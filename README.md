# Discover Bangladesh

A static travel guide website about Bangladesh, built with plain HTML, CSS and JavaScript.

## View it
Open `index.html` in any browser, or run a local server:

```bash
npx serve .
```

## Files
- `index.html`: page content
- `styles.css`: styles, including light and dark themes
- `script.js`: mobile menu, destination filter, image lightbox, demo contact form

## Notes
- The contact form is a demo only. It sends nothing. To make it work, connect a backend or a form service.
- Photos load from Wikimedia Commons. Credits are listed in the page footer.
- Visa, permit and safety rules change. Check official sources such as https://www.visa.gov.bd/ before publishing.
